## About Siam On Cloud

**Siam On Cloud** is a technology company focused on building digital platforms, automation systems, and modern software solutions for travel businesses, service operators, and growing organizations.

We combine product strategy, software engineering, cloud infrastructure, workflow automation, and practical AI to create systems that are simple to use, scalable, and ready for real-world operations.

Our approach is centered around one principle:

> **Technology should reduce complexity, not create more of it.**

## Engineering Principles

We believe good software should be:

**Simple**  
Easy for users and internal teams to understand and operate.

**Reliable**  
Designed for real-world business operations, not just demos.

**Scalable**  
Built with future growth in mind.

**Secure**  
Security is treated as part of the architecture, not an afterthought.

**Maintainable**  
Code and systems should remain understandable over time.

**Automation-first**  
Repetitive work should be automated whenever practical.

## Security

Security is a core part of our development process.

Our practices may include:

- Least-privilege access control
- Protected branches
- Multi-factor authentication
- Secure environment variables
- Dependency monitoring
- Access review
- Secure API design
- Backup and recovery planning

Please do not publish sensitive credentials, API keys, passwords, personal data, or production secrets in public repositories or issues.
